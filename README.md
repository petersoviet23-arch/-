VK 文献智能整理 v1.0
===========================
功能：自动识别 PDF、EPUB、DJVU、DOCX、ZIP、RAR 等真实扩展名；从 PDF 前五页或元数据提取书名，通过 DeepSeek 生成中文候选书名；人工核对后批量重命名。

第一次运行：
1. 电脑需安装 Python 3.10 或更新版本（安装时勾选 Add Python to PATH）。
2. 双击「安装依赖.bat」安装 PyMuPDF。
3. 双击「一键启动.bat」。
4. 默认扫描目录 C:\Users\35540\Downloads\VK_文献资料，也可以自由选择其他目录。
5. 如果需要自动翻译，请在软件中填写 DeepSeek API Key（软件不保存密钥）。模型默认 deepseek-flash，具体以账户支持的模型为准。翻译将产生 API 费用。
6. 点击「扫描文件 + 生成中文候选书名」，检查每个拟修改文件的名称。
7. 需要时双击文件行修改中文书名；再点击「应用勾选的重命名」。
8. 操作日志在文献目录下 _整理日志 文件夹。日志为 CSV，可用于查找旧名称并手动恢复。

扫描件 OCR（可选）：
- 安装 Tesseract OCR 并安装俄语 rus + 英语 eng 语言包。
- 将 tesseract.exe 所在目录添加到 PATH。
- 勾选「扫描版启用 OCR」。程序仅在页面可提取文字太少时 OCR 前五页，不会改写 PDF。
- OCR 未安装或识别失败时，不会伪造中文译名。

重要：
- PDF 标题、扫描页 OCR 和机器翻译均可能出错；必须人工核对书名。
- 文件格式无法识别时，程序直接跳过，不乱改扩展名。
- 原 PDF 内容不修改，仅改磁盘文件名。已有同名文件不会被覆盖。
- 仅 PDF 文件自动尝试从内页提取书名；其他格式当前只修正扩展名。
- 如果未设置 API Key，程序只提取原书名和修复扩展名；中文书名可手动编辑。
- API 仅接收文件名、PDF 元数据和前几页文本摘录，不上传完整 PDF。
- 为避免隐私问题，敏感文献请关闭 DeepSeek 自动翻译。
